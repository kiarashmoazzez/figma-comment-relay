# Changelog

All notable changes to Comment Relay will be documented here. The project follows semantic versioning once it reaches `1.0.0`.

## [Unreleased]

- OAuth or session-only token strategy for production onboarding.
- Real-file integration tests in Figma Desktop.
- Accessibility and keyboard-navigation audit.
- Additional matching fixtures from representative production files.

## [0.1.0] - 2026-11-19

### Added

- Local capture of native Figma comments and threaded replies.
- Multiple searchable and editable comment collections.
- Confidence-based structural matching and proportional coordinate mapping.
- Manual placement using the current Figma selection.
- Selective native comment import with source attribution and mention protection.
- Duplicate-import prevention and deletion of comments imported by the current user.
- JSON collection export/import.
- Dependency-free plugin UI with standalone preview states.
- Matcher unit tests and deterministic build script.
